# 检查矩阵

`scripts/audit_docx.py` 用的编号。**级别**：`严重` = 必须清零；`提示` = 按体裁判断。

## 排印（T）

| 编号 | 检查 | 判定 | 级别 |
|---|---|---|---|
| T1 | 正文行距不足 | 中文正文字号 ≤ 14pt 且行距倍数 < 1.6 | 严重 |
| T2 | 正文字号不合档 | 正文字号 < 10 或 > 12pt | 提示 |
| T3 | 字号档数过多 | 全篇不同字号（按 0.5pt 计）> 7 | 严重 |
| T4 | 大标题行距不足 | 字号 ≥ 18pt 且行距倍数 < 1.3（中文） | 严重 |
| T5 | 中文负字距 | 含中文的 run 字距 < 0 | 严重 |
| T6 | 全大写拉丁无正字距 | run 全大写且字距 = 0 | 提示 |
| T7 | 行长超限 | 版心 ÷ 正文字号 > 40 汉字 或 < 20 汉字 | 严重（> 40）/ 提示（< 20） |
| T8 | 两端对齐 | 正文段落 `justify` | 严重 |
| T9 | 表格网格线 | 表格有 `insideH`/`insideV` 或四边框 | 严重 |
| T10 | 表格对齐错位 | 数字列左对齐 / 文本列右对齐 | 提示 |
| T11 | 首行缩进 | 正文段落首行缩进 > 0 | 提示 |
| T12 | 字体族过多 | 全篇字体族 > 2 | 严重 |
| T13 | 缺页码 | 无页脚或页脚无页码域 | 提示 |
| T14 | 中文斜体 | 含中文的 run 为斜体 | 严重 |
| T15 | 行距为多倍而非固定值 | 正文段落 `line_spacing_rule != EXACTLY` | 提示 |
| T16 | 表格缺单位 | 表头与表注都没有「单位」字样 | 提示 |

## 书写（W）

| 编号 | 检查 | 判定 | 级别 |
|---|---|---|---|
| W1 | 破折号当标点 | 出现 `—` / `——` / `--` | 严重 |
| W2 | 直引号 / 英文引号 | 出现 `"` 或 `'` | 严重 |
| W3 | 三个点 | 出现 `...` | 提示 |
| W4 | 数字与单位缺空格 | `\d(亿元|万元|万台|万套|个月|条|台|人|元|吨)` | 严重 |
| W5 | 百分号前有空格 | `\d %` | 严重 |
| W6 | 中英混排缺空格 | 汉字紧跟拉丁字母，如 `PDF文档` | 提示 |
| W7 | 禁用词 | 赋能 / 闭环 / 抓手 / 一站式 / 极致 / 大幅 / 显著 / 轻松 / 一键 … | 严重 |
| W8 | 绝对化断言 | 唯一 / 最 / 第一 / 全部 / 完全 / 必然 / 零缺陷 | 提示 |
| W9 | 段落过长 | 段落 > 4 句，或单句 > 60 字 | 提示 |
| W10 | 泛化标题 | 概览 / 概述 / 结语 / 小结 / 其他 / 更多 / 详情 / 备注 | 提示 |
| W11 | 主语混用 | 「公司」与「我们 / 笔者 / 本人」同篇出现 | 严重 |
| W12 | 单位口径混用 | 同篇 `亿元` 与 `万元`；或 `个百分点` 与 `pt` 混用 | 严重 |
| W13 | 模糊量词无数字 | 大幅 / 显著 / 较多 / 左右 / 约 / 超过… | 提示 |

## Excel（X，`scripts/audit_xlsx.py`）

| 编号 | 检查 | 判定 | 级别 |
|---|---|---|---|
| X1 | 网格线未关 | `showGridLines` 为真且表内数值 ≥ 10 | 严重 |
| X2 | 数字格式缺失 | 数值单元格为 `General`（金额 ≥ 1000 或比率 < 1） | 严重 |
| X3 | 数字左对齐 | 同一表内 ≥ 3 个数值显式左对齐 | 提示 |
| X4 | 列宽不够 | 右侧有内容时，文本宽度 > 列宽 × 1.05 + 1（会被截断/####） | 严重 |
| X5 | 行高不够 | 字号 ≥ 12pt 但行高 < 字号 × 1.2 | 提示 |
| X6 | 字体族过多 | 字体族 ≥ 3（≥ 4 判严重） | 提示 / 严重 |
| X7 | 字号档数 / 过小 | 字号 > 7 档，或出现 < 9pt | 提示 |
| X8 | 全网格边框 | 四边都有框的单元格 > 30% | 严重 |
| X9 | 表头无区分 | 首行未加粗且数据 ≥ 3 行 | 提示 |
| X10 | 未冻结表头 | > 20 行且无 `freeze_panes` | 提示 |
| X11 | 无打印设置 | 数值 ≥ 10 但无 `print_area` / 未 `fitToWidth` | 提示 |
| X12 | 数字列夹文字 | 数字之后又出现文字（求和会被跳过） | 严重 |
| X13 | 文本型数字 / 百分点存成 % | 数字存成文本 ≥ 2 个；或纯 `0.0%` 格式配值 > 1.5 | 严重 |
| X14 | 合并单元格过多 | 合并 ≥ 5 处且占比 > 8% | 提示 |
| X15 | 无单位声明 | 数值 ≥ 5 且全表无「单位」 | 提示 |

书写规则（W）对 Excel 同样生效：单元格文本会逐格送进 `text_rules.py`，位置写成 `Sheet!A1`。

## PowerPoint（P，`scripts/audit_pptx.py`）

| 编号 | 检查 | 判定 | 级别 |
|---|---|---|---|
| P1 | 正文字号过小 | 含中文的正文 run < 16pt | 严重 |
| P2 | 一页要点过多 | 非标题段落 > 6 条 | 严重 |
| P3 | 一页在念稿 | 非标题字数 > 120 | 严重 |
| P4 | 标题字号过小 | 标题 < 24pt | 提示 |
| P5 | 字号档数过多 | 全篇 > 5 档 | 提示 |
| P6 | 字体族过多 | ≥ 3 族（≥ 4 判严重） | 提示 / 严重 |
| P7 | 中文斜体 | 含中文的 run 为斜体 | 严重 |
| P8 | 全大写无字距 | 全大写拉丁且 `a:rPr@spc` ≤ 0 | 提示 |
| P9 | 图表带网格线 | `value_axis.has_major_gridlines` 为真 | 提示 |
| P10 | 没有大纲结构 | 非占位符文本框 > 60% 且 ≥ 3 个 | 提示 |
| P11 | 画幅不是 16:9 | 宽高比偏离 16:9 超过 3% | 提示 |
| P12 | 图片无替代文本 | 图片 `descr` 为空 | 提示 |
| P13 | 表格四边框线 | 单元格显式画了 lnL/lnR/lnT/lnB 且 ≥ 3 行 | 提示 |
| P14 | 缺标题 | 无标题占位符或标题为空 | 提示 |
| P15 | 列表层级过深 | 段落 level > 2（第 3 级及以下） | 提示 |

幻灯片的标准比文档严：**一页一个主张**，正文不小于 16pt，一页不超过 6 条 / 120 字。

## 不在脚本里、必须人看的三件事

1. **数字勾稽**：分项之和、同比、跨表一致性。脚本不认业务口径。
2. **事实矛盾**：「利润下滑」与「净利 +8.7%」这种，需要读懂句子。
3. **层级是否清楚**：截图看一眼（Word 转 PDF 后按页看），脚本只能数出字号档数。

这三件在 `SKILL.md` 的第 4 步「交付前自检」里逐条列出。
