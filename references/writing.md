# 书写规范（writing）

来源：Vercel `writing-guidelines`（pinned 83e2316），按中文企业文件重排。原文面向英文开发者文档，这里保留判断标准、换掉不适用的项（`you` 直呼、缩写、大小写）。

编号与 `scripts/audit_docx.py` 输出一致，可按号查。

---

## 一、事实与数字（最高优先）

- **W-矛盾**：同一文档内不得自相矛盾。「净利润 +8.7%」与「利润下滑」不能并存；「未因准则变更调整」与「2024 年数据经追溯调整」不能并存。
- **W-勾稽**：分项之和 = 合计；本期/上期 − 1 = 同比；表内同名指标与正文一致；跨表（利润表 ↔ 关键指标）一致。
- **W-主体**：写「增速比去年低 3.1 个百分点」必须说清是营收增速还是净利增速。
- **W4 数字与单位之间加空格**：`48.62 亿元`、`2,180 万元`、`3.1 万台`、`148 万套`。
- **W5 百分号与数字之间不留空格**：`6.7%`（不是 `6.7 %`）；千分位用半角逗号 `2,180`。
- **W12 单位口径全篇一致**：
  - 金额只用一种主单位（`亿元` 或 `万元`），换单位要在表注声明
  - 变动用 `个百分点`，不写成 `pt` 也不写成 `%`（`+1.4 个百分点`）
  - 同一指标在正文与表格里单位必须相同
- **W13 模糊量词要么删要么给数**：`大幅`、`显著`、`明显`、`较快`、`较多`、`超过两成`、`左右`、`约` —— 后面必须跟数字，或改成具体说法。

---

## 二、语气与主语

- **W11 主语统一**：全篇只用一种。企业文件推荐「公司」（正式）或「我们」（致辞、对内）；**不要**在同一篇里公司 / 我们 / 笔者 / 本人混用。无主语句（「已完成锁价」「已对 60% 用量锁价」）也要补主语。
- **主动语态**：能说出「谁做了什么」就不要用被动。测试法：句尾加「被谁」，加不上就是没主语。
- **一句一个概念**：一句里不要塞两个指标。`营收 48.62 亿元、同比增长 12.4%，净利 5.31 亿元、同比增长 8.7%` → 拆两句。
- **W9 段落 2–4 句，单句 ≤ 60 字**：超了就拆。分段是为了让读者有换气的地方。
- **不用反问句**（像广告）：`难道不是这样吗？` → 直接陈述。
- **不用「我们」代替「你」**：对外文件里读者是「股东 / 客户 / 审批人」，不是「我们」。

---

## 三、禁用词与 AI 腔

**W7 禁用词**（营销腔、无信息量）：

`赋能`、`闭环`、`抓手`、`生态化`、`一站式`、`极致`、`领先`、`完美`、`轻松`、`一键`、`快速`、`大幅`、`显著`、`极大`、`全面提升`、`深度赋能`、`助力`

英文对应：`easy`、`simple`、`quick`、`very`、`just`、`really`、`seamless`、`robust`、`leverage`。

**W8 绝对化断言**（无数据支撑就删）：
`唯一`、`最`、`第一`、`全部`、`完全`、`必然`、`彻底`、`零缺陷`

**AI 腔的六个特征**（见到就改）：

| 特征 | 例子 | 改法 |
|---|---|---|
| 摘要式过渡 | 「在完成了上述配置之后…」 | 直接进下一点：「实际部署时…」 |
| 碎片化停顿 | 「以前是手工的。现在是自动的。这省了时间。」 | 合成一句 |
| 参数表口吻 | 「该模块提供可配置的…」 | 说人话：谁用它、解决什么 |
| 冷开场 | 段首第一句像小标题，前文没有铺垫 | 用「因为…」「在…之后」接上上文 |
| 拟物化 | 「令牌拿着请求」「数据在管道里跑」 | 用实际动作 |
| 模板化框架 | 「大多数团队面临的问题是…」 | 换成本文特有的处境 |

## 四、结构与标题

- **开篇一段 TL;DR**：这份文件讲什么、给谁看、结论是什么。年报用「导语」承担。
- **每节开头一句总述**：读者只看每节第一句也能知道这节在说什么。
- **W10 标题要具体**，禁止泛化词：`概览`、`概述`、`结语`、`小结`、`其他`、`更多`、`详情`、`备注`。改成能预判内容的：`经营概览` → `2025 年经营结果`；`结语` → `2026 年的承诺`。
- **层级不超过三层**（章 / 节 / 条目）。企业文件很少需要第四层。
- **术语首次出现给定义**：行业缩写（`pt`、`EBITDA`、`在手订单`）第一次出现写全，或加注。
- **列表**：三项以上并列改成列表；列表用冒号引入；条目是短语就不加句号。

---

## 五、标点与字符

- **W1 不用破折号当标点**：`—`、`——`、`--` 都不行。改用冒号、逗号、句号，或重写句子。（引文署名可以用中点 `·`。）
- **W2 中文用全角引号**：`「」` 或 `“”`，不用直引号 `"` `'`。
- **W3 省略号用 `……`**，不用 `...`。
- **W6 中英混排加空格**：`iPhone 16`、`PDF 文档`、`2025 年 3 月`。
- **W5 全角标点用在中文句子里**（，。；：？！），半角只用在纯拉丁串里。
- 括号：中文括号 `（）`，其中纯拉丁内容可用半角 `()`。

---

## 六、加粗与强调（与排印共管）

- 加粗只给**关键事实**（一个数字、一个结论），不给语气。
- 预算：**每 400 字 ≤ 2 处**。超了就说明句子本身不够有力，改句子。
- 不用加粗做小标题（那是标题的活）；不用颜色做强调（打印丢失）。

---

## 七、输出格式（审计结果）

固定格式，一行一条，便于 agent 迭代：

```
文件:位置 编号 问题 → 改法
```

例：

```
年报.docx:p7  W-矛盾 净利润 +8.7% 与「利润下滑」并存 → 改「增速放缓」或改事实
年报.docx:p12 W4 「48.62亿元」→「48.62 亿元」
年报.docx:t3r2 W12 「+1.4pt」→「+1.4 个百分点」
```

最后给一行统计：`严重 N 条 / 提示 M 条`。严重项清零才交付。
