# 排印规范（typography）

来源：OpenDesign `craft/typography.md` + `typography-hierarchy.md` + `typography-hierarchy-editorial.md`，按中文办公场景重排。
规则分三级：**硬规则**（必须满足）、**默认**（除非有理由）、**提示**（看情况）。

---

## 1. 字号阶梯

**默认**：比例 1.2–1.25，一件文档最多 **7 档**（含标题与注释），一屏可见不超过 3 档。

| 角色 | 网页 / px | Word / pt | 说明 |
|---|---|---|---|
| 封面主标题 | 56–96 | 26–36 | 编辑级可到 40pt |
| 章标题 H1 | 32–48 | 18–22 | |
| 节标题 H2 | 24–32 | 14–16 | |
| 小标题 H3 | 20–24 | 12–13 | 多数企业文档不需要 |
| 正文 | 15–18 | **10.5–12** | 中文正文建议 11–12pt |
| 次要信息 | 13–14 | 9–10 | 作者、日期、单位说明 |
| 注释 / 表注 | 11–12 | 8–9 | |

**硬规则**：正文与表注之间的字号差至少 2pt；同一层级（例如所有章标题）必须同字号、同字重、同颜色。

---

## 2. 行距（leading）

**硬规则 —— 中文覆盖，无上位豁免**：

| 字号档 | 拉丁 | **中文** |
|---|---|---|
| 大标题 ≥ 24pt | 1.0–1.2 | **1.3–1.4** |
| 节标题 14–22pt | 1.15–1.3 | **1.35–1.45** |
| 正文 10.5–12pt | 1.5–1.6 | **1.7–1.8** |
| 注释 8–10pt | 1.4–1.5 | **1.5–1.6** |

原因：拉丁字的升部/降部在 em 框内留有空隙，大标题可以压到 1.0；**中文字身撑满 em 框**，同样的 1.05 会让相邻两行笔画相碰。中文封面标题 26pt 以上折行时最容易踩，**第一个要检查的就是封面主标题**。

**落地**：Word 用「固定值」而不是「多倍行距」——多倍行距由渲染器按各自字体行高计算，跨机器会变。正文 12pt × 1.8 = **固定值 22pt**，大标题 30pt × 1.35 = **固定值 41pt**。

---

## 3. 字距（tracking）

| 场景 | 字距 |
|---|---|
| 正文 | `0` |
| 小字 8–9pt | `+0.01em`–`0.02em` |
| 全大写拉丁 | **`+0.06em`–`0.1em`（必须）** |
| 标题 ≥ 24pt（拉丁） | `-0.01em`–`-0.02em` |
| 展示级 ≥ 36pt（拉丁） | `-0.02em`–`-0.03em` |
| **中文任何字号** | **`0`，禁止负字距** |

**硬规则**：全大写不加正字距 = 业余感的最强信号；中文套拉丁负字距 = 字挤在一起。中英混排时（英文 kicker 压中文大标题），紧字距**只设在拉丁那个 run 上**，不要让父级样式继承给中文块。

Word 落地：字符间距用 1/20 pt（`w:spacing w:val`），9pt 字的 0.08em = 0.72pt = `val="14"`。

---

## 4. 行长（measure）

**硬规则**：中文正文 **20–35 字/行**，拉丁 50–75 字符/行。

- CSS：`max-width: 36em`（中文）/ `65ch`（拉丁）
- Word：版心宽度 ÷ 字号 ≈ 汉字数。A4 左右各 3.0cm → 版心 15cm，12pt 中文 ≈ **35 字/行**
- Excel：不适用（表格按列宽控制）

超过 40 字/行时不要缩字号救命，**收版心**。

---

## 5. 对齐

- **硬规则**：正文 `text-align: start`（左对齐，右边缘参差）。**禁止两端对齐** —— 中文没有词间空格，`justify` 只能拉伸字间空隙，正文里出现一道道白色裂缝（rivers）。
- 数字列右对齐；文本列左对齐；表头与数据同侧对齐。
- 标题禁止居中（封面除外）。

---

## 6. 段间距与首行缩进

- 中文长文：**段落之间用间距分开，不用首行缩进**（缩进 0 + 段后 6–10pt）。首行缩进是纸媒排版的历史习惯，在屏幕上会与段间距重复表达同一件事。
- 段后间距全篇一致；章节前的空间要**大于**段后间距（至少 2 倍）。
- 不用空段落制造间距（会被复制、会破分页）。

---

## 7. 层级：五个向量一起用

层级不只靠字号。五个向量：**字号 / 字重 / 留白 / 字距 / 对齐破格**。

**硬规则**：
1. 每个视觉区域内**只有一个主导元素**（读者第一眼落点）；两个同级并列 = 没有层级
2. 主导元素至少有两个向量同时在起作用
3. 相邻两级不能「同字号 + 同字重 + 同间距」
4. 一屏可见层级不超过三层：主导 / 支撑 / 附注

**反模式**：
- 字重阶梯：regular → medium → semibold → bold → extrabold，每级加一档 —— 这是默认清单，不是设计
- 全篇区块间距一样 —— 没有节奏，读起来像清单
- 标题很大很粗、其余全平 —— 只有字号一个向量在工作
- 全篇都是重点（很多加粗）—— 加粗预算：**每 400 字不超过 2 处**，且只给「关键事实」，不给语气

---

## 8. 字体

**默认**：一件文档**最多 2 个字体族**（标题族 + 正文族）。企业文档用系统字体，不引外链字体。

| 场景 | 中文 | 拉丁 / 数字 |
|---|---|---|
| 标题（正式） | 宋体 / 思源宋体 | Times New Roman |
| 标题（现代） | 微软雅黑 / 思源黑体 | Segoe UI / Inter |
| 正文 | 微软雅黑 / 思源黑体 / 苹方 | Segoe UI / Inter |
| 数字（表格、指标） | — | Segoe UI / Helvetica，配合等宽数字 |

**硬规则**：
- 中文**不用斜体**（没有真正的斜体字形，渲染是伪斜，笔画发虚）。强调用字重或颜色。
- 全篇字体族 ≤ 2。Word 内置 `Title`/`Heading`/`Quote` 样式会偷偷带进 Calibri、等线、Times 斜体 —— 导出 PDF 时一并暴露。
- 数字用**等宽数字**（`tabular-nums` / `font-variant-numeric`），表格里小数点才能对齐。

---

## 9. 颜色

**默认**：60% 中性 / 30% 辅助 / 10% 主色。正文与背景对比 ≥ 4.5:1，大字 ≥ 3:1。

- 强调色全篇 **≤ 2 处**（封面一条线 + 一个关键数字，就够）
- 现有文档里最常出的问题：浅灰字（`#999`）配白底，对比度不足 3:1
- 红绿不要互指（色盲）；涨跌用符号 + 数字，不只靠颜色
- 打印黑：正文用 `#111`，不用纯 `#000`（激光打印会糊边）

---

## 10. 表格

**硬规则**：
1. **关掉网格线**。表格只保留：表头下一条细线（0.5–0.75pt）、表尾一条粗线（1.0–1.5pt）、行间可选极浅细线（透明度 15–20%）。**不画竖线**，不画外框。
2. 数字**右对齐**，位数对齐；文本列左对齐；单位写在表头（`营业收入（亿元）`），不要每格重复
3. 表格必须有单位声明（表题或表注），且与列内单位一致
4. 合计行：加粗 + 上方一条细线；不与明细行同字重
5. 表注 8–9pt、灰色，与表体之间留一行空白
6. 表格不跨页：行设 `cantSplit`，整表 `keep_with_next`（除末行）

---

## 11. 分页（PDF / 打印尤其重要）

**硬规则**：
- 章标题不与正文分离（`keep_with_next`）
- 表格、图、拉引不跨页
- 页末不留孤行（一段的最后一行单独跑到下一页）
- 每章起新页（正式报告）；内页短文档可按内容流排

**默认**：封面无页眉页脚、不编号；内页页眉（公司 + 文件名）+ 页脚页码「第 x 页 / 共 y 页」。

---

## 12. 编辑级排版（年报、白皮书、对外长文）

在以上规则之上额外三条：

1. **戏剧化跳级**：展示级与正文的比值 3–5×，不要 1.5×
2. **拉引**（pull quote）：28–40pt、**常规字重**、无边框无底色、打破版心（全宽或单侧内收）、全篇 1–2 处
3. **疏密交替**：区块间距不要全等 —— 密 / 疏 / 中 交替，读者才有节奏

---

## 13. 优先级冲突

规则打架时的顺序：

1. 可读性（行距、行长、对比度）
2. 事实正确（数字、单位、口径）
3. 层级清楚
4. 视觉风格

任何「为了好看」的改动如果伤到 1 或 2，改回去。
